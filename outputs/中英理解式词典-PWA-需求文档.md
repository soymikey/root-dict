# 中英理解式词典 PWA 需求文档

## 一、产品目标

开发一款以手机使用为主的中英双向翻译 PWA。产品不仅提供翻译，还通过词根、词缀、词源历史、词族关系和记忆联想，帮助用户理解并记住英文单词。

## 二、目标用户

- 以中文为母语的英语学习者
- 习惯在手机上快速查词和翻译句子的用户
- 希望通过理解单词来源来加强记忆的用户

## 三、核心功能

### 1. 中英双向翻译

- 中文翻译成英文
- 英文翻译成中文
- 自动识别输入语言
- 支持单词、短语和句子
- 单词与句子采用不同的结果布局
- 中文查询得到多个英文候选词时，可以点击其中一个查看详情

### 1.1 语音输入

- 翻译页输入框右侧提供麦克风按钮
- 用户点击按钮后请求麦克风权限并开始识别
- 支持中文和英文语音输入
- 识别结果先回填到输入框，由用户确认或修改后再翻译
- 录音期间显示明确的聆听状态，并提供停止按钮
- 识别失败、权限被拒绝或浏览器不支持时，显示简短提示并保留键盘输入
- 优先使用 Web Speech API 的 `SpeechRecognition`
- 由于该功能并非所有主流浏览器都支持，不能把语音输入作为完成查询的唯一方式
- 部分浏览器会把音频发送到在线识别服务，因此不能承诺离线可用

### 2. 单词故事卡

英文单词详情包含：

- 核心中文释义
- 美式音标
- 词性和常见词形变化
- 前缀、词根和后缀拆解
- 单词来源和词义演变
- 常见同词根词族
- 近义词及使用区别
- 中英双语例句
- AI 生成的记忆联想

真实词源与 AI 助记内容必须分开显示。无法确认的词源信息应标记为“不确定”，不能编造。

### 3. 发音

- 点击英文单词即可播放发音
- 同时提供扬声器按钮
- 默认使用美式英文声音
- 没有美式声音时自动切换到其他英文声音
- 支持整句朗读
- 点击句子中的英文单词，可以单独发音并打开该词的故事卡
- 播放时提供高亮或播放状态反馈
- 使用 Web Speech API 调用手机系统声音
- 离线发音能力取决于设备是否安装了对应声音

### 4. 本地保存

- 单词故事卡提供“保存”按钮
- 保存后按钮显示“已保存”
- 使用 IndexedDB 保存到当前设备
- 同一个单词不能重复保存
- 再次查询时优先显示已保存内容
- 提供“重新生成”更新内容
- 生词库支持搜索、删除和“已掌握”状态
- 离线时仍可查看已保存单词

### 5. OpenAI API

- 用户自行输入 OpenAI API 密钥
- 密钥只保存在当前页面运行内存中
- 刷新或关闭应用后清除
- 不得写入本地数据库、日志或离线缓存
- Service Worker 不得缓存 OpenAI 请求和认证信息
- 界面需要提示浏览器直连 API 的安全风险
- 使用小模型生成翻译、词源解释、词族和助记内容
- AI 返回固定结构数据，方便稳定展示

### 6. PWA 能力

- 支持安装到手机主屏幕
- 以移动端单手操作为主要设计目标
- 缓存应用页面和已保存的单词
- 离线时显示明确状态
- 离线状态不能生成新翻译，但可以查看生词库
- 电脑浏览器保持基本可用，不制作独立桌面版

## 四、UI 与交互规范

- 整体定位为偏 iOS 的简洁风格，参考 Apple Human Interface Guidelines，但不追求像素级仿原生
- 采用清晰、克制、内容优先的视觉层级，使用中性色背景和单一强调色
- 主要依靠留白、字号、字重和轻量分隔线组织内容，减少不必要的卡片容器
- 以 iPhone 竖屏和单手操作为主要使用场景，同时保证 Android 手机基本可用
- 尊重顶部状态栏、Dynamic Island 和底部 Home Indicator 的安全区域
- 使用系统字体栈，并支持系统字体放大，文字不得截断或相互重叠
- 支持浅色模式和深色模式，并保证足够的文字与控件对比度
- 所有可点击控件的触控区域至少为 44 × 44 点
- 主要操作放在拇指容易触达的中部或底部区域
- 底部标签栏包含“翻译”“生词库”“设置”三个入口
- 返回、关闭、清空、发音、麦克风、保存等操作优先使用熟悉的图标，并提供可访问标签
- 每个页面只突出一个主要操作；次要操作降低视觉权重
- 使用清晰的按下、加载、成功、失败和禁用状态反馈
- 动画保持短促自然，只用于页面切换、保存确认和播放状态等必要反馈
- 避免堆叠大量装饰卡片、夸张渐变、重度玻璃效果和复杂动画
- UI 借鉴 iOS 的信息层级与交互习惯，不直接复制受限制的 Apple 视觉资产

## 五、页面结构

### 翻译页

- API 密钥状态入口
- 大尺寸输入框
- 自动识别语言方向
- 翻译按钮和清空按钮
- 翻译结果、发音和保存操作

### 单词故事页

- 单词、音标、发音和释义
- 构词拆解
- 词源故事
- 词族关系
- 记忆联想
- 近义词对比
- 双语例句
- 保存状态

### 生词库

- 已保存单词列表
- 搜索
- 未学习、学习中、已掌握状态
- 打开详情和删除

### 设置页

- 输入或清除 API 密钥
- 默认美式发音
- PWA 安装入口
- 数据和隐私说明

## 六、第一版暂不包含

- 注册和登录
- 云端同步
- 俄语或其他语言
- 社交、排行榜和分享社区
- 复杂课程、测试和复习算法
- 独立桌面版
- 自建语音服务
- 本地数据导入和导出

## 七、验收标准

- 可以在手机上完成中英双向翻译
- 在支持的浏览器中，可以通过麦克风输入中文或英文，并在翻译前编辑识别文字
- 浏览器不支持语音识别或用户拒绝麦克风权限时，键盘输入仍可正常使用
- 英文单词可以生成完整的单词故事卡
- 点击英文单词可以播放默认美式发音
- 单词卡可以保存到本地，刷新后仍然存在
- 离线时可以查看已保存内容
- API 密钥不会被持久化或缓存
- PWA 可以安装到手机主屏幕
- 常见手机尺寸下内容不重叠，主要操作可单手完成
- 所有核心触控目标不小于 44 × 44 点，并正确避开 iPhone 安全区域
- 系统字体放大和深色模式下，页面仍然可读且可操作
